## 宿題

- 取り組んだレベル：**基礎**
- やったこと：`app/agent.py` の `INSTRUCTIONS` から「用語や講座に固有のことを答える前に、必ず `search_glossary` で用語集を確認する。」という指示を削除した。変更前後に同じ質問「LoRAとQLoRAの違いは？」を `--trace` 付きで実行し、ツール呼び出しと回答を比較した。その他の指示やツール定義は変更していない。
- 結果：

  | 比較項目 | 変更前 | 変更後 |
  |---|---|---|
  | `search_glossary` 呼び出し回数 | 2回 | 1回 |
  | 検索引数 | `LoRA`、`QLoRA` | `LoRA` |
  | LLM呼び出し回数（`requests`） | 2回 | 2回 |
  | 入力トークン数 | 1,196 | 899 |
  | 出力トークン数 | 172 | 192 |
  | 回答の要旨 | LoRAは低ランク行列のみを学習し、QLoRAはベースモデルを量子化してメモリを節約する | 同様の違いを説明 |

  変更前は `search_glossary({'query': 'LoRA'})` と `search_glossary({'query': 'QLoRA'})` の2回呼び出された。変更後は `search_glossary({'query': 'LoRA'})` の1回のみとなった。両方ともLoRAとQLoRAの違いを説明し、関連する回として第2回を示した。入力トークン数は297減ったが、LLM呼び出し回数は変わらなかった。
- 気づき・疑問：`INSTRUCTIONS` の1行を削除しただけで、ツールの呼び出し回数と引数が変化した。このことから、AIエージェントのツール利用は、利用可能なツールの定義だけでなく、モデルに与える指示にも影響されると分かった。一方、検索を必須とする指示を削除しても検索自体は行われ、回答の要旨も維持された。今回は1問ずつの比較であり、指示の変更による一般的な傾向を断定することはできない。今後は質問の種類や実行回数を増やし、根拠の確認がどの程度安定して行われるかを調べたい。
